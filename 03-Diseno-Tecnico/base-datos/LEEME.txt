03-Diseno-Tecnico/base-datos
============================
NIVEL DE INFORMACIÓN: TÉCNICO DETALLADO (la base de datos por dentro)

PROPÓSITO
  Reunir todo lo de la base de datos con el estándar de nombres aplicado.

QUÉ VA
  generar_diccionario.py   Fuente única: valida el estándar y genera los 3 archivos siguientes.
  diccionario-datos.md     Cada tabla y columna con su nombre físico, tipo y descripción.
  diccionario-datos.xlsx   El mismo diccionario en Excel con filtros (Tablas, Columnas, Valores, Indices).
  modelo-er.md             Modelo Entidad-Relación en Mermaid.
  scripts/                 Scripts SQL puntuales.
  scripts-bd/              Script completo de la base por cada paso a producción.

QUÉ NO VA
  Datos reales (clientes, pedidos). Solo estructura y datos de ejemplo.

ORDEN DE LECTURA
  1) ../12-estandar-base-datos.md  2) diccionario-datos.md  3) modelo-er.md

QUIÉN / CUÁNDO
  Se actualiza cada vez que cambia un modelo. Anotar en 00-Gestion/11-decisiones-cambios.md.
